## はじめに

Aether Canvas はソースからビルドします。安定版の Rust（1.82 以上、[rustup.rs](https://rustup.rs) から入手）が必要です。

```sh
git clone https://github.com/syuumaimikan/Aether-Canvas
cd Aether-Canvas
cargo run --release -p aether-desktop                  # エディタを起動
cargo run --release -p aether-desktop -- art.aether    # ファイルを開いて起動
```

Vulkan・Metal・DirectX 12・OpenGL のいずれかに対応した GPU ドライバが必要です。Linux ではさらに `libxkbcommon` と X11 または Wayland のクライアントライブラリが必要です。

初回起動時は、ステータスバーにチュートリアルの案内が出ます。表示言語は **ウィンドウ › 言語**（English／日本語）、配色は **ウィンドウ › テーマ**（ダーク・ライト・ハイコントラスト）で切り替えられます。

## 画面構成

* **メニュー**（上端）：ファイル・編集・レイヤー・フィルター・イメージ・リグ・表示・ワークスペース・ウィンドウ・ヘルプ。
* **パネル**（キャンバスの周り）：ツール・ツールオプション・レイヤー・カラー・ブラシ・ヒストリー・プロパティ・エフェクト・パラメータ・リグ・ダイナミクス・タイムライン。タブをドラッグして移動し、別のパネルの端に落とすと分割、タブ列に落とすと重ねて配置できます。
* **ワークスペース**（ワークスペースメニュー）は作業ごとのパネル配置です：*イラスト*、*ドット絵*（ピクセルグリッド・硬いブラシ・ニアレストネイバー表示）、*コンポジット*、*リギング*、*アニメーション*。切り替えてもドキュメントはそのままです。
* **ステータスバー**には、ツール・表示倍率・キャンバスサイズ・選択中のレイヤーと、直前の操作の結果（やったこと、うまくいかなかった理由）が表示されます。

## 絵を描く

1. **ブラシ**（`B`）を選びます。*ツールオプション* でサイズ・不透明度・流量・硬さ・間隔・手ブレ補正を調整します。**ブラシ** パネルにはプリセットやブラシ先端（紙のテクスチャ、画像スタンプ）があり、自作のプリセットを保存して JSON ファイルとして共有できます。
2. **筆圧**は OS が報告する場合にサイズなどへ反映されます。*筆圧の取得元* で、ペンの代わりにストロークの速度を使う・使わないを選べます。
3. 色は **カラー** パネル（描画色と背景色、16 進、パレット、最近使った色）で選びます。`X` で入れ替え、スポイト（`I`）でキャンバスから拾えます。
4. **消しゴム**（`E`）はブラシの形で消します。**塗りつぶし**（`G`）は近い色の範囲を塗ります。許容値と *Sample all layers*（全レイヤーを参照）はツールオプションにあります。
5. **選択範囲**（矩形・楕円・投げ縄・自動選択）で、描画・塗りつぶし・フィルター・変形を範囲内に限定できます。新規・追加・除外・交差のモードはツールオプションで切り替えます。
6. **自由変形**（`Ctrl+T`）は、拡大縮小・回転・斜め変形・自由な歪み・メッシュワープを 1 つの枠で行います。`Enter` で確定、`Esc` で中止し、変形全体が 1 回の取り消しになります。**ゆがみ**（`Shift+L`）で画素を押し出し・渦巻き・縮小・膨張できます。

すべての変更は取り消せます。**ヒストリー** パネルに一覧が並び、項目をクリックするとその時点に戻れます。

## レイヤー・エフェクト・調整レイヤー

* **レイヤー** パネルで、レイヤーの追加・グループ化・複製・削除・並べ替えができます。各レイヤーに不透明度・合成モード（23 種類）・表示・ロック・透明部分をロック・「下のレイヤーでクリッピング」があります。
* **グループ**は中身をまとめて合成するか、パススルーで中身を下のレイヤーと個別に合成します。
* **マスク**でレイヤーの一部を消さずに隠せます（*選択範囲からマスクを作成*）。
* **エフェクト**（エフェクトパネル）は非破壊です：ぼかし・モーションブラー・シャープ・グロー・ドロップシャドウ・縁取り・カラーオーバーレイ・ノイズ・色調補正。並べ替えやオン／オフができ、画素ではなく設定として保存されます。
* **調整レイヤー**（レイヤー › 新規調整レイヤー）— レベル補正・トーンカーブ・色相／彩度・露光量・カラーバランスなど — は、下にあるものを書き換えずに見た目を変えます。
* **フィルター** メニューは同じエフェクトを画素に直接適用します。エフェクトを焼き込むと、見ていたものとまったく同じ画像になります。

## ファイル・PSD・ZIP・サンプルライブラリ

| ファイル | 開く | 保存・書き出し |
| --- | --- | --- |
| `.aether` プロジェクト | ファイル › 開く | ファイル › 保存 — JSON と PNG の ZIP（[FILE_FORMAT.md](FILE_FORMAT.md)） |
| PNG・JPEG・WebP・TIFF・BMP・GIF | ファイル › 開く（新規ドキュメントとして） | ファイル › PNG形式で書き出し（PNG・JPEG・WebP） |
| レイヤー付き PSD | ファイル › 開く | ファイル › PSDを書き出し |
| Live2D モデル（`.model3.json`） | ファイル › Live2D モデルを開く… | ファイル › Live2D モデルを書き出し… |
| 上記を含む ZIP | ファイル › 開く、またはサンプルライブラリ | — |

ファイルはウィンドウにドラッグ＆ドロップしても開けます。

**PSD** は、フォルダ・合成モード・不透明度・クリッピング・マスク・日本語のレイヤー名を、読み込み・書き出しの両方で保ちます。

### ZIP ファイル

ZIP は展開せずにそのまま開けます。中身がモデル・PSD・プロジェクト・画像のうち 1 つだけならすぐに開き、複数あるときはサイズ付きの一覧から選べます。ZIP の中の ZIP も読み、日本語版 Windows で作られた ZIP のファイル名（Shift_JIS）も正しく表示します。モデルのテクスチャは一覧に出しません。Cubism Editor のプロジェクト（`.cmo3`・`.can3`）は開けませんが、そこから書き出したランタイムモデル（`.model3.json`）は開けます。

### サンプルライブラリ

**ファイル › サンプルライブラリ…** は、サンプルフォルダ内で開けるもの（フォルダ内のファイルと、各 ZIP の中身）を一覧にし、クリックで開けるようにします。絞り込みもできます。

1. ダウンロードしたサンプルを、エディタを起動するフォルダ（`cargo run` ならリポジトリのフォルダ）かアプリと同じ場所の `assets_sample` フォルダに置きます。環境変数 `AETHER_SAMPLES` で別の場所も指定でき、起動中は *フォルダを選ぶ…* で任意のフォルダを選べます。
2. 各行に種類（Live2D モデル・PSD・画像）・サイズ・名前・場所（`pack.zip › runtime` など）が表示されます。名前や種類で絞り込めます。
3. **開く** で開きます。*PSD を開いたら自動リグ* にチェックすると、PSD を読み込んだ直後にリグを付けます。大きな PSD は数秒かかりますが、その間もエディタは操作でき、何を開いているかがステータスバーに出ます。

`assets_sample/` は git の管理対象外にしてあります。サンプルキャラクターには個別の利用規約があり、多くは再配布を認めていないためです。

## キャラクターにリグを付ける

リグはレイヤーを動くキャラクターにする仕組みです。**パラメータ**（`AngleX`・`EyeLOpen`・`MouthOpenY` など）が、メッシュ・**デフォーマ**（ワープと回転）・**ボーン**の **キーフォーム**（キーの値ごとに記録した形）を動かします。各要素の詳しい説明は [RIGGING.md](RIGGING.md) にあります。

### かんたんな方法：自動リグ

1. 顔・白目・瞳・まつげ・眉・口・髪（前・横・後ろ）・体などをレイヤーに分けた PSD を開きます。フォルダ分けされているとより正確です。
2. **リグ › 自動リグ**（リギングワークスペースの *✨ 自動リグ*）を選びます。すべてのレイヤーをメッシュ化し、次のものを 1 回の取り消しで戻せる操作としてまとめて作ります。
   * 立体的な **顔の向き**（`AngleX`・`AngleY`）、首の傾き（`AngleZ`）、体の向きと傾き、**呼吸**
   * **まばたき**と**笑顔の目**、見回す**瞳**（`EyeBallX/Y`）、**眉**、開閉して笑う**口**、**頬染め**
   * 物理演算で揺れる**髪やアクセサリー**
   * 自動まばたき・視線追従・頭に合わせて動く体・**待機モーション（Idle）**
3. **パラメータ** パネルのスライダーを動かして確認し、**物理プレビュー**（`Shift+P`）をオンにすると、まばたき・呼吸・揺れがリアルタイムで動きます。

認識できたパーツの数と、動かないまま残ったパーツの名前がステータスバーに表示されます。**レイヤー名を直してもう一度自動リグを実行する**のが一番早い直し方です（毎回リグを作り直します）。

#### レイヤー名の付け方

英語・日本語の名前を大文字小文字を区別せずに読み取り、左右は `L`/`R`、`left`/`right`、`左`/`右` で判断します（キャラクターから見た左＝画面の右）。全一覧は [RIGGING.md の Auto rig](RIGGING.md#auto-rig) にあります。よく使うもの：

| パーツ | 名前 |
| --- | --- |
| 顔 | face, 顔, 輪郭, 肌 |
| 白目・瞳・まつげ | 白目 · 瞳, 目玉, 黒目 · まつげ, 二重 |
| 眉・口・頬 | 眉, まゆ · 口, 口 開き, 舌 · 頬, 照れ |
| 髪 | 前髪 · 横髪, もみあげ · 後ろ髪, ポニー, テール · アホ毛 |
| 体と服 | 体, 服, 上着, シャツ, スカート, 脚, 腕, 手 |
| リグから外す | 原画, 下書き, ラフ, 背景, bg |

Live2D のサンプルのような素材分け PSD もそのまま使えます。

* **汎用的な名前のレイヤー**（`線`・`塗り`・`影`・`レイヤー 3`）は、入っているフォルダの役割を引き継ぎます。`前髪/線` は前髪です。
* **A/B の差分**（`腕A_L`・`腕B_L`：腕を下ろす／組むなど）には **Variant** パラメータが付き、0 で A、1 で B を表示します。
* **両目にまたがる**レイヤーは、それぞれ近い方の目に追従します。目の中にあるクリッピング用レイヤーも目と一緒に閉じます。
* **マスクはパーツと一緒に動きます。**

### 手作業で仕上げる

* **オブジェクトを選ぶ**：**リグ** パネル（デフォーマ・ボーン・メッシュのツリー）で選ぶか、キャンバスをクリックします。
* **メッシュツール**（`U`）：頂点の追加・移動・削除。*リグ › 自動メッシュ* で選択中のレイヤーを、*全レイヤーをメッシュ化* ですべてを作り直します。ツール使用中は基本ポーズで表示されます。
* **キーフォーム**：パラメータパネルでオブジェクトのパラメータをキーの位置に合わせ（スライダーが ◊ の印に吸い付きます）、**変形ツール**（`W`）で形を整えます。パラメータを右クリックすると、最小・既定・最大へのキー追加、反対側のキーへのミラー、ブレンドシェイプやドライバの追加ができます。
* **デフォーマ**：*リグ › + ワープデフォーマ*、*+ 回転デフォーマ* で選択中のオブジェクトを包みます。リグパネルのジェネレーターで、ワープに *3D顔向き*・揺れ・つぶれを自動で作れます。
* **ボーン**（`K`）：チェーンを描き、メッシュをスキニングします。IK 制約でチェーンを目標に向けられます。
* **物理演算**（ダイナミクスパネル）：頭や体の角度で動く振り子チェーン。重力・風・硬さ・角度制限・コライダーがあります。*標準の物理と自動挙動* で、標準パラメータ用の髪の揺れ・まばたき・呼吸を追加します。
* **ドライバ**はパラメータを他のパラメータから計算します。`BodyAngleX = self + AngleX * 0.3` で体が頭についてきます。

## アニメーション

1. **アニメーション** ワークスペースに切り替えると、キャンバスの下に **タイムライン** が表示されます。
2. **+ モーション** でモーションを作ります（初期値は 3 秒。長さ・FPS・ループはタイムラインで変更できます）。
3. **アニメート** と **自動キー** をオンにし、目盛りをクリックして再生位置を動かしてからパラメータをドラッグすると、その位置にキーが打たれます。`Shift+K` で全パラメータにキー。キーはドラッグでタイミングを変え、選ぶとイージング（ステップ・直線・ベジェ・イーズ・バック・弾性・バウンス・スプリング）を変えられます。
4. `P` で再生、`,` と `.` で 1 フレームずつ移動します。物理プレビューがオンなら、髪や服がモーションについてきます。
5. **口パク**：*WAVを読み込み…* のあと *口パクを焼き込み* で、音声から口のキーを作ります。
6. **表情**は、モーションの上に重ねるパラメータの組み合わせ（笑顔・怒りなど）です。**ダイナミクス** パネルの *取り込み* で、既定値から動かしたパラメータを表情として保存し、クリックでプレビューできます。
7. **書き出し**：リグ › *GIFを書き出し…*、*APNG を書き出し…*（フルカラー・半透明対応）、*PNG連番を書き出し…*、*スプライトシートを書き出し…*（JSON のアトラス付き）。物理演算を事前に動かしておき、揺れが落ち着いた状態から書き出すこともできます。

モーションと表情は Live2D の `.motion3.json`・`.exp3.json` としても読み込み・書き出しでき、Aether のタイムラインで Live2D モデル用のモーションを作れます。

## Live2D モデルと VTube Studio

**開く**：ファイル › *Live2D モデルを開く…* で `.model3.json`（またはそのフォルダ、モデル入りの ZIP）を開きます。Cubism と同じ見た目で表示され、パラメータ・パーツ・モーション・表情・物理演算・まばたき・口パクが Aether のリグデータになり、そのまま動かしたり書き出したりできます。

**書き出す**：ファイル › *Live2D モデルを書き出し…* で、`NAME.model3.json`・`NAME.moc3`・テクスチャ・物理演算・表示名・モーション・表情を 1 つのフォルダに書き出します。開いた Live2D モデルは、編集した部分以外はそのまま書き戻されます。Aether でリグを付けたキャラクターは新しい Cubism モデルになり、Cubism と同じ計算で頂点ごとに照合したうえで、近似した点がウィンドウに一覧表示されます。

**VTube Studio で使う**：書き出したフォルダを VTube Studio の `Live2DModels` フォルダ（インストール先の `VTube Studio_Data/StreamingAssets/Live2DModels`）にコピーし、VTube Studio を起動してモデルを選びます。まばたきと口パクはモデルに登録済みなので VTube Studio が動かし、標準パラメータ名（`ParamAngleX`・`ParamEyeLOpen` など）は設定なしでフェイストラッキングにつながります。

## ゲーム・アプリ・Web

ファイル › *ランタイムモデルを書き出し…* で `model.json` とテクスチャアトラス（公開形式の JSON と PNG）を書き出します。Aether のランタイムは、すべてのリグ機能をエディタと同じように再生します。詳しくは [RUNTIME.md](RUNTIME.md) を参照してください。

* **Web プレイヤー**（WebAssembly + WebGL）：ポインタ追従・タップ・マイクでの口パク・**ウェブカメラのフェイストラッキング**
* **Godot 4** の `AetherModel2D` ノード、**Unity** の `AetherModel` コンポーネント
* ネイティブのエンジンやアプリ向けの **C API** と Rust クレート

## コマンドライン

```text
aether-canvas [オプション] [ファイル]
```

ファイルには、`.aether` プロジェクト・PSD・`.model3.json`・画像・Live2D モデルの入ったフォルダ・ZIP を指定できます。ZIP 内の 1 つは `pack.zip#中のパス` で指定します。

| オプション | 内容 |
| --- | --- |
| `--list [フォルダ\|ZIP]` | サンプルフォルダやアーカイブの中身を、開けるパスとして 1 行ずつ表示（既定は `assets_sample`） |
| `--export-model 出力先` | ウィンドウを開かずにランタイムモデルとして書き出す |
| `--export-live2d 出力先` | Live2D Cubism モデルとして書き出す |
| `--auto-rig` | 書き出しの前に、レイヤー名から自動リグを付ける |
| `-h`, `--help` ／ `-V`, `--version` | ヘルプとバージョン |

```sh
aether-canvas --auto-rig --export-live2d vtuber character.psd
aether-canvas --list assets_sample
aether-canvas --auto-rig --export-model web "assets_sample/pack.zip#chara/parts.psd"
```

## 困ったときは

* **Linux でエディタが起動しない** — `libxkbcommon-x11`（またはディストリビューションの同等のパッケージ）と Vulkan か OpenGL のドライバを入れてください。足りないものはエラーメッセージに出ます。
* **自動リグ後に動かないパーツがある** — ステータスバーに名前が出ます。そのレイヤー名を直して（[レイヤー名の付け方](#レイヤー名の付け方)）もう一度自動リグを実行するか、手作業でリグを付けてください。
* **顔を振り向かせると後ろのものが見える** — 大きな角度では、顔の後ろのレイヤー（後ろ髪、首の影など）が見えることがあります。*Head* ワープを選んでリグパネルの *3D顔向き* を小さい角度でやり直すか、隠れていた部分を削ってください。
* **腕のポーズが 2 つ同時に表示される** — PSD に A/B という名前でない差分が入っています。片方のレイヤーを非表示にするか、`…A` ／ `…B` に名前を変えて自動リグをやり直すと、Variant で切り替えられます。
* **大きな PSD が重い** — 45 MB・270 レイヤーの PSD では、読み込みと自動リグに 20〜30 秒、メモリを約 2 GB 使います。素材レイヤーをパーツごとに 1 枚へ統合すると（Live2D 読み込み用に作られた PSD のように）大幅に速くなります。
* **Live2D の書き出しで差が報告される** — 書き出しウィンドウに、近似した内容（物理演算・ドライバ・数ピクセル以上ずれたパーツ）とその理由が一覧表示されます。パラメータやモーションには影響しません。
* **ショートカット・言語・テーマの場所** — ヘルプ › ショートカット一覧、ウィンドウ › 言語、ウィンドウ › テーマ。
